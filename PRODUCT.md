# Product

## Register

product

## Users

Non-technical stakeholders and curious builders exploring the Portaldot blockchain without SDK knowledge. They open Hermes during active investigation — checking network state, querying an address, understanding protocol parameters. They are not writing code; they are getting answers. Power users will live in the keyboard.

## Product Purpose

Hermes is a natural-language interface to the Portaldot chain. It translates plain English questions into on-chain queries and returns precise technical answers instantly. Success looks like a user who would otherwise need the substrate-interface SDK getting the same answer in seconds, without any setup.

## Brand Personality

Technical, precise, fast. A serious tool that respects the user's intelligence. No softening, no hand-holding, no decoration that slows the interface down. Confident like a well-tuned CLI — but readable by anyone.

## Anti-references

- AI chatbot aesthetic: floating message bubbles, soft pastels, "friendly bot" rounded cards, emoji-laden responses. Hermes is an agent, not a companion.
- Crypto/web3 neon: particle backgrounds, glow overload, dramatic gradients on every surface. The blockchain is the product; the UI is the instrument.
- Generic SaaS dark mode: purple hero gradients, glassmorphism as decoration, feature grids with icons and padding.
- Startup landing page templates: testimonial carousels, "Join X companies" social proof, feature-benefit columns.

## Design Principles

1. **Answer first.** Every screen exists to surface information. Structure, spacing, and hierarchy serve legibility — not aesthetics.
2. **Speed is a feature.** Interactions must feel instantaneous. Perceived latency is a design failure, not a backend problem.
3. **Confidence, not friendliness.** Copy and UI patterns should be direct and exact. Avoid softening language, filler words, and decorative empty states.
4. **Keyboard-native.** The primary interaction model is typing. Mouse affordances exist, but keyboard flow must be seamless and discoverable.
5. **Earn every element.** If a UI element does not carry information or enable an action, it should not exist. Decoration is debt.

## Accessibility & Inclusion

WCAG AA minimum. Keyboard navigation is a first-class interaction model — focus rings, skip links, and tab order are not afterthoughts. Reduced motion: respect `prefers-reduced-motion` for all transitions and looping animations.
